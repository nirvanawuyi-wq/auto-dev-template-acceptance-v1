## 三、通用约束（每一组都适用）

- **只写在独立分支，开 PR。** 分支名 `d3/<组号>`。由我审、我合入 `main`。**你不要自己合并，不要改规则集，不要碰 `main`、`integration`、`production`。**
- **令牌不写进任何脚本、图、提示词、日志。** 脚本只用服务器上 `agent` 已登录的 `gh`；通知地址和令牌只从服务器的仓库外配置读取，仓库里只写变量名或"读取服务器配置"。
- **仓库是公开的**：不写服务器地址、域名、账号名、`chat_id`。
- 所有脚本：`#!/usr/bin/env bash`、`set -euo pipefail`；输出不打印任何密钥值；退出码语义写在脚本头注释里。
- 所有自动修复循环最多 3 次，耗尽后通知，不静默继续。
- **不要改**测试、检查配置、`.github/` 下的任何文件、`.github/protected-paths.txt`（这些属于受保护路径）。你写的东西只放 `.ai/cezar/workflows/`、`.ai/bin/`、`.ai/prompts/` 和 `docs/`。
- 用于 runner：干活 agent 用 `[干活 agent，例如 codex]`，审查和代决用 `[审查 agent，和干活 agent 不同家族，例如 claude]`。
- 凡你**没有实际运行过**的行为，一律标【待验证】，不要写成"已验证"。
