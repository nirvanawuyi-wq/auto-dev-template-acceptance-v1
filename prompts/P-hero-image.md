# 首页主图生成提示词

阅读项目简介，为「{项目名称}」生成一张首页主图，表现「{项目主题或用途}」。画面聚焦「{关键主体或场景}」，面向「{目标用户}」，表达「{项目氛围}」，配色与页面的主色「{主题色}」协调。内容项目优先用能承载主题的照片或插画，工具项目可用解释用途的原创示意图。

- 桌面目标为 **1920 × 1080 px（16:9）**。主体的关键部分尽量留在画面中央约 45% 的宽度内，四周留出裁切空间。
- 手机版优先将同一张图居中裁为 **4:5**。主体被裁切时，保持主体和光线一致，另做 **960 × 1200 px（4:5）** 的竖图。
- 生成单张图片素材。标题和按钮由网页渲染，图中保持无文字、无标志、无水印。保留实际输出尺寸，按目标比例裁切时保持原始比例。
- 将预览样图放在 Git 忽略的 `local/` 下。在桌面和手机实际打开首页核对构图和主体。演示采用虚构素材时，在页面标为「示例图」。
